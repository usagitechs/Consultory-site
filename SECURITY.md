# Política de seguridad

Si encontrás una vulnerabilidad en este sitio o en su código, escribinos a **usagiteks@gmail.com** con el asunto `[security]`. Respondemos en menos de 72 horas hábiles. Por favor no abras un issue público hasta que lo hayamos corregido.

Alcance: este repositorio (sitio estático en GitHub Pages) y el formulario de contacto. Fuera de alcance: servicios de terceros (EmailJS, Cloudflare, GitHub) — reportá directamente a ellos.
